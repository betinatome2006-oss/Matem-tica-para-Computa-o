# Matem-tica-para-Computa-o
Uma disciplina importante para desenvolver o raciocínio lógico e compreender conceitos na área da Computação. A matemática ajuda na resolução de problemas, na criação de algoritmos e no desenvolvimento de soluções mais eficientes, sendo uma base importante para diversas áreas da tecnologia.
